# 小与封面图：品牌规范

## 来源与确定性

附图1是12张平台封面的截图，附图2是小与IP多视图及表情设定。截图可以判断视觉风格，不能确认原始字体名称，也不能反推出未经压缩的品牌色。下面色号是按视觉观察建立的新品牌标准，不宣称是原作者源文件的精确参数。字体是为本技能统一指定，不宣称鉴定出了原图字体。

## 固定项

| 项目 | 固定规则 |
| --- | --- |
| 标题字体 | 庞门正道粗书体；粗笔刷、厚重、略有飞白、利落尖锐收笔。标题与辅助字统一字形体系。内置生成按该字体视觉拟合，不能称为已使用真实字体文件。 |
| 字体处理 | 右倾约10°，文字行整体上扬0°至5°；纯色填充，炭黑细描边与短投影。避免厚重3D字、金属字与每张换一种书法。 |
| 强调色 | 荧光黄绿 `#B7FF00`，用于标题关键词、少量划线或细箭头；不能整幅染绿。 |
| 对照字色 | 纯白 `#FFFFFF`，用于标题的解释、结果或问题。两版同一行文案使用同一色号。 |
| 暗部 | 炭黑 `#111315`，用于环境暗部、标题描边与阴影，保留纹理层次。 |
| 场景灯光 | 暖金 `#C6923B`，用于真实灯具、反光与轮廓光。不是标题填充色。 |
| 中性色 | 中灰 `#777B80`，用于金属、设备与环境过渡。白上衣保持中性，肤色自然。 |
| 色彩面积建议 | 环境暗色约55%至65%，暖金约15%至25%，白色与肤色约15%至20%，荧光绿约5%至10%；按画面面积估计，不要求逐像素统计。 |
| IP | 永远是 `assets/xiaoyu-ip.png` 中的同一人；保留短黑发、发际线、五官比例、脸型与身材。表情与姿势可以变化。 |
| 服装 | 白色高领无袖上衣、黑色高腰宽松裤、黑色短靴、银灰挂绳。近景裁切时无需强行露出裤子与靴子。 |
| 风格 | 写实人物＋电影感场景合成＋粗笔刷编辑标题＋少量荧光手绘强调＋明确前中后景。人物可信、背景有故事、缩略图可读。 |

标题优先将行动或主题设为荧光黄绿，将解释或结果设为白色。主标题通常2至3行，合计8至16个中文字符；每行4至7字更适合竖版。英文如AI可同列，避免额外切换英文字体。小署名“小与封面图”固定白色，字号小于标题但缩小后仍可辨认。

## IP位姿与表情

参考图提供正面、侧面、背面，以及微笑、惊讶、欣喜、大笑、调皮、眨眼、俯视、仰拍、斜角俯拍。后面三项主要是观察角度，不应误当成独立表情。

| 内容 | 推荐动作 | 推荐表情与景别 |
| --- | --- | --- |
| 展示工具/功能 | 向镜头递手机或展示道具，身体略转30° | 微笑/欣喜，中近景；手和道具大于背景设备 |
| 避坑/反转/提问 | 坐在桌前，一手扶桌或举道具 | 惊讶/挑眉，中景；看镜头或看道具 |
| 教程/流程/复刻 | 握场记板、指向实物或少量流程面板 | 专注/微笑，中景；肩颈姿态自然 |
| 成果/震撼场景 | 指向后景或向画面伸手 | 欣喜，人物中景＋场景远景 |
| 轻松效率话题 | 坐姿使用手机，或转身回望 | 微笑/调皮，中近景 |

动作变化不能改变人物身份。默认单一主角；内容确实要求“一个人演多个角色”时才增加同IP的背景分身，主角仍最大最清晰。没有授权不更换成长发、原图1演员、其他年龄、其他面孔或古装主角。

### 身体透视冲击与情绪价值

优先让主IP具备以下至少一种表现力；内容适合时可结合，不为追求夸张牺牲身份、可读性或主题可信度。动作表是起点，不是每张固定套用的姿势。

| 方向 | 设计方法 | 示例与边界 |
| --- | --- | --- |
| 身体透视冲击 | 一个身体部位靠近镜头，躯干处于中景，场景退向远景；利用缩短透视、斜向动作和遮挡制造3D纵深 | 向观众递道具、张掌邀请进入场景、前臂伸出画面、一步迈向镜头。优先手或前臂，不必强行露脚；不是把普通姿势的手单独放大。 |
| 情绪共鸣 | 将情绪落实到眉眼、嘴部、视线、肩颈与躯干动作，而非只写“开心” | 成果揭晓时前倾欣喜；避坑时挑眉并举掌提醒；流程完成时肩膀放松、释然微笑；探索时侧身探看、好奇凝视。严肃主题不强行大笑。 |

- 透视型可从约24至35mm等效的适度广角、轻低机位或斜侧机位尝试；这是创作参考，不是每张强制镜头。让近景手与前臂明显大于远处部位，同时保持关节连接、肢体长度与重心可信。脸留在中景，避免贴镜头产生鱼眼式五官变形。
- 先写清“身体朝向、哪只手做什么、最近部位、视线目标、支撑点”，再描述视觉冲击。单个主要前景动作即可；手、道具、AR面之间要有正确遮挡、接触和投影。可裁切前景边缘，但不让手掌遮住眼睛、嘴或标题。
- 情绪型优先一项主情绪，并配一项身体语言。惊讶可轻后仰、睁眼和微张嘴；坚定提醒可举掌、目光直视；轻松调皮可侧倾、挑眉或眨眼。避免所有情绪都变成张嘴大笑，也不凭空用恐惧、愤怒或崩溃制造与视频不符的冲突。
- 横竖两版保持同一动作意图、主情绪、视线对象与交互道具；允许调整身体角度、机位和肢体占幅以适应排版，不要求机械复制姿势。固定IP图锁定身份与服装，不锁死其站姿或棚拍角度。
- XR/AR背景不能替代主IP的表现力：主IP应主动递出、触碰、指引或回应内容，而不是站在一堆面板前。若主题更适合安静、专注的情绪，以清晰身体语言呈现，不硬加冲镜动作。
- 正反例、前后对比或布光图例需要控制变量时，示例中的姿势、视角和表情保持可比；让主IP主持动作更有表现力，不通过改变示例表情冒充效果差异。

## 两版构图

坐标以下以画布左上角为(0%,0%)，是构图指导区间而非强制像素框。统一四边安全边距5%，文字底部留6%余量。

| 版式 | 标题 | IP | 纵深与负空间 |
| --- | --- | --- | --- |
| 3:4，768×1024 | 左上或上方，约x=5%至78%、y=6%至35%；优先2至3行 | 偏右或中下，身体覆盖约45%至60%画面宽；头部约y=35%至55%，自然按姿态调整 | 道具/伸手在下方前景；人物为中近景；走廊、工作室、设备为远景；标题后景压暗 |
| 4:3，1024×768 | 左侧，约x=5%至52%、y=12%至58%；同文案可改换行 | 偏右，身体覆盖约40%至50%画面宽；面部约x=70%至82%、y=28%至45% | 前景可从右下进入，人物与文字之间留间隙；环境向左右延展；保留相同背景线索 |

两版同样使用：主标题字高约短边的8%至12%，署名字高约短边的2.5%至3.5%；标题行距约0.95至1.08倍字高，保持足够辨识空间。必要时减字号、改换行或移动人物，不遮挡眼睛、嘴、关键道具，不裁断笔画。

可选三种构图变体：展示型（文字左、人物右、道具近）、反应型（文字上、人物中下、桌面前）、成果型（文字左上、人物右下、远景占比稍大）。字体、IP和灯光不随变体改变。

视频模式额外支持XR/AR沉浸型与多案例/证据对比型，规则见video-to-cover.md。优先2至3个图例面，必要时最多4个。主IP仍最大最清晰；小图中的同IP布光/效果示范属于教学图例，不是新增故事角色或身份设定表。为保留真实布光差异，图例局部可有冷暖、明暗变化，全幅主环境和主IP仍保持本色系。

## 前中后景与灯光

- 前景：一项与主题有关的实物，或伸向镜头的手；可用透视放大形成引导。边缘可轻度虚化，关键展示内容须清晰。
- 中景：小与的人脸、上身和互动姿态，人物最清晰，脸部用中性柔光，不整体染成橙色或绿色。
- 后景：有可辨识空间结构的黑金工作室、走廊、书架或对应主题场景；远景亮度与细节密度低于人物。采用金色实景灯与透视线，不靠满屏散光点。
- 氛围：暗底亮人、暖背景与中性白衣对照。少量荧光线连接标题和道具，最多一条主划线加一条细箭头，避免装饰喧宾夺主。

## 验收

检查两版文案、同一IP、固定服装、字体笔画风格、同一行的绿白分配、黑金背景、自然肤色、前中后景、标题无遮挡，以及实际比例和像素。按约25%尺寸观察，应先读到标题和脸，之后才看到道具和环境。平台爱心、点赞数、播放按钮、进度条、截断描述及系统水印属于源截图界面，不属于封面风格，全部排除。

另检查位姿：缩略图中能否读出一个明确动作或情绪；透视冲击是否来自真实近远关系而非身体畸变；眉眼、嘴部与身体语言是否一致；手指、关节、支撑及遮挡是否合理。冲击力不以遮脸、遮字、过度广角或夸张肢体比例为代价。
